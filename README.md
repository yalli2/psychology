# The Psychology Book — Interactive Study Site

Interactive class site for *The Psychology Book* (DK, "Big Ideas Simply Explained").

- **index.html**: main page listing all 7 chapters and 102 thinkers, with search and progress tracking
- **chapter.html?p=1 … 7**: per-chapter pages with four tabs
  - Learn · Practice: summary, key points, context timeline, key terms, a discussion question, and 5 scored practice questions for each thinker
  - Chapter test: 10, 20, 30 or all questions, drawn at random, with a score
  - Matching game: pair each thinker with their big idea
  - Flashcards: thinkers and key terms
- Language switcher (top right): English · 한국어 · Español · 中文 · 日本語
- Scores are saved in the browser (localStorage) on each device

All summaries and questions were written fresh for classroom use. They do not reproduce the book's text.
